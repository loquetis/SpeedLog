Automatic tests

Tests run only while SpeedLog is running (window open or minimized, or in the tray). Each test uses up to about 260 MB of data: up to 200 MB down and 60 MB up, so pick a longer interval on a metered connection.

Your plan (optional)

Draws a dashed line on the charts so you can see how far the real speed is from what you pay for. Leave at 0 for no line.

Running in the background

Data

Results are stored on this PC only, in %APPDATA%\SpeedLog. Tests talk to Cloudflare's public speed test servers (no account). Your public IP and ISP name are recorded with each result.
